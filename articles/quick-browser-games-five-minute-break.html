Try one traffic run in Cat Crossing, a few turns in Rainbow Roll, or a calendar board in Meeting Mayhem. These three Blueberry Basement games open directly in the Minit web player.

Cat Crossing for one-tap timing

Read the traffic from the grass and tap to hop one row when a gap opens. A collision ends the run. There is no finish line, so five minutes is a budget you set yourself. Try beating your first score if there is time left.

Rainbow Roll for steering and braking

The linked course opens with a ball, a winding path and an on-screen control. Hold and drag to steer, then release to brake before a tight turn. For a quick break, focus on keeping the ball on the first few bends. Coins are a second goal once you can hold the line.

Play Rainbow Roll →

Meeting Mayhem for a timed logic puzzle

In Fresh Start, drag movable meetings into open slots and leave the fixed cards alone. Read the move counter and timer before choosing a gap. The post has three calendars, so you can try the first board if time is tight or continue through all three.
